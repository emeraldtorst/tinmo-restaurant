# TINMO frontend engineering

The shared brief owns the *what* (tokens, type scale, motion, placeholder policy, media). This skill owns the *how*: where code lives, what each component is responsible for, and which patterns are banned. This is not the Next.js of your training data (16.4, React 19.3, Tailwind 4.3). Before using a Next API read its guide under `node_modules/next/dist/docs/01-app/` (`01-getting-started/05,11,12,13,14`, `02-guides/json-ld.md`, `02-guides/preventing-flash-before-hydration.md`). Copy is British English; identifiers are US (`color`).

## 1. Architecture

```
src/
  app/            layout.tsx page.tsx globals.css icon.svg opengraph-image.* robots.ts sitemap.ts not-found.tsx menu/page.tsx
  components/
    layout/       Navbar.tsx MobileMenu.tsx Footer.tsx
    sections/     Hero.tsx HeroVideo.tsx StorySection.tsx SignatureDishes.tsx AtmosphereGallery.tsx GuestReviews.tsx VisitSection.tsx ReservationCTA.tsx
    ui/           Button.tsx ReserveButton.tsx ReservationDialog.tsx Reveal.tsx RevealText.tsx MediaImage.tsx Eyebrow.tsx Container.tsx MapPlaceholder.tsx
  content/        site.ts hours.ts menu.ts dishes.ts reviews.ts media.ts gallery.ts story.ts navigation.ts   <- ALL editable copy/data
  lib/            cn.ts reservation.ts directions.ts structured-data.ts reviews.ts                          <- pure functions, no JSX
  types/          content.ts                                                                                <- every shared data contract
```

The only permitted additions to this tree are the route error boundaries `app/error.tsx` and `app/global-error.tsx` (section 8). Do not add other folders under `src/` or other files in `src/app/`.

- **Imports flow left to right only:** `types` <- `content` <- `lib` <- `ui` <- `sections`/`layout` <- `app`. `ui` never imports `sections`; `sections` never import `content/*` (page.tsx imports content and passes typed props); `content` imports only `@/types/content`. Always use the `@/` alias, never `../../`.
- **Root layout composition** (`app/layout.tsx`): font variable classes on `<html>`, the motion-ok script in `<head>`, then `<body>` = skip link, `ReservationProvider` wrapping `Navbar` + `<main id="main">{children}</main>` + `Footer`. Navbar/Footer get `site` and `navigation` from `content/*` here; sections get theirs from `page.tsx`.
- **Server by default.** `"use client"` only at the leaf that needs state, effects, refs or handlers (files marked client below). Never mark a whole section client to make one handler work: extract the leaf and pass server-rendered content as `children`.
- **Props crossing into a client file must be serialisable** (strings, numbers, booleans, plain objects, arrays). No functions, `Date`, `URL`, class instances. Content files export plain `as const satisfies` objects.
- One component per file; filename = export name (PascalCase); `export default function X` for components, named exports for types/helpers, no barrel `index.ts`. Props interface is named `XProps`, sits above the component, and is exported only if reused.
- **Clear responsibility:** a file has one reason to change. Over ~150 lines, more than 3 boolean props (use a `variant` union), a third copy of the same markup, or prop drilling deeper than 2 levels (use `children`/composition) means split or extract into `ui/`.
- **Static rendering stays static.** Do not call `cookies()`, `headers()`, `connection()` or read `searchParams` in `app/**`; do not add `"use cache"` (`cacheComponents` is off). Use the globals `LayoutProps<"/">` / `PageProps<"/menu">` (generated by `next dev|build|typegen`, no import); `params` and `searchParams` are Promises, so `await props.params`. TINMO has no dynamic segments.
- Effects return cleanup (`observer.disconnect()`, `removeEventListener`). Keys come from `id`, never array index. No commented-out code, no `TODO`/`FIXME`/lorem in `src`. Comments say *why*.

## 2. Component responsibilities

Runtime: **S** server, **C** client (`"use client"`), **X** shared (no directive, no hooks; importable from either side).

| Component | Rt | Owns (and nothing else) | Props contract |
|---|---|---|---|
| `Navbar` | C | Fixed bar; transparent over hero, `bg-paper` + 1px `border-line` once `[data-hero-sentinel]` leaves view (one IntersectionObserver, no scroll listener); no sentinel on the page (`/menu`) => solid at once; owns menu open state | `{ links: readonly NavLink[]; wordmark: string }` |
| `MobileMenu` | C | Full-screen overlay as a native `<dialog>` (`showModal()`): focus trap, Esc, focus restore, 500ms clip/opacity, stacked serif links | `{ links: readonly NavLink[]; open: boolean; onClose: () => void }` |

| `HeroVideo` | C | Variant pick, play/pause logic, poster fallback, visible pause control (WCAG 2.2.2) | `{ video: VideoAsset }` |
| `StorySection` | S | `#story`, 02; asymmetric editorial layout, max 1 arch image | `{ story: StoryContent }` |
| `SignatureDishes` | S | `#menu`, 03; dish list, placeholder note, full-menu link | `{ dishes: readonly Dish[]; menuLink: { href: string; external: boolean } }` |

| `RevealText` | S | Splits a string into word (70ms) or letter (90ms) spans inside one `Reveal variant="mask-up"`; full text stays readable (`sr-only` copy + `aria-hidden` spans) | `{ text: string; as: "h1" \| "h2" \| "h3" \| "p"; by?: "word" \| "letter"; emphasis?: string; delay?: number; className? }` |
| `MediaImage` | C | `next/image` wrapper: aspect box, truthful `sizes`, blur, focal point, `onError` fallback | `{ asset: ImageAsset; sizes: string; priority?: boolean; quality?: 60 \| 75 \| 85; shape?: "rect" \| "arch" \| "circle"; className? }` (`sizes` is required on purpose) |
| `Eyebrow` | S | `02 — Story` (index, em-dash, label) + hairline; indexes: Hero 01, Story 02, Plates 03, Atmosphere 04, Guest notes 05, Visit 06, Reserve 07, Footer 08 | `{ index: string; label: string; tone?: "light" \| "dark" }` |
| `Container` | S | The only owner of horizontal padding and max width | `{ width?: "wide" \| "narrow"; as?: "div" \| "section"; className?; children }` |
| `MapPlaceholder` | S | Fine-line abstract map (no real geography), `role="img"` + label "Map placeholder — location to be confirmed" | `{ className? }` |

`className` props are for layout only (margin, grid placement, position). There is no `tailwind-merge`, so never rely on overriding a component's own colour, size or radius utilities from outside.

## 3. Typed content contracts (`src/types/content.ts`)

```ts
export type Weekday = "Mon" | "Tue" | "Wed" | "Thu" | "Fri" | "Sat" | "Sun";
export interface Confirmable<T> { value: T | null; confirmed: boolean }   // null + false => UI shows the placeholder string
export interface NavLink { label: string; href: `/#${string}` | "/menu" }
export interface Credit { license: string; source: string; sourceUrl: string; author: string | null }

export interface ImageAsset {
  id: string;                          // registry key, e.g. "dish-black-cod"
  src: `/media/${string}`;             // self-hosted under public/media, never remote
  width: number; height: number;       // intrinsic px of the master (drives aspect ratio)
  alt: string;                         // specific; "" only when decorative
  decorative?: boolean;
  blurDataURL: string; color: string;  // from scripts/optimize-image.mjs; color = average colour
  focal: { x: number; y: number };     // 0-100, becomes object-position
  caption?: string; credit: Credit; isPlaceholder: boolean;
}
export interface VideoSource { src: `/media/${string}`; type: "video/mp4" | "video/webm"; variant: "portrait" | "landscape-720" | "landscape-1080" }
export interface VideoAsset { id: string; sources: readonly VideoSource[]; poster: ImageAsset; durationSec: number; label: string; credit: Credit }

export interface Dish { id: string; name: string; description: string; price: string | null; image: ImageAsset; isPlaceholder: boolean }
export interface ReviewSource { kind: "illustrative" | "google" | "manual"; listingUrl: string | null; isPlaceholder: boolean }
export interface Review { id: string; quote: string; author: string | null; rating: 1 | 2 | 3 | 4 | 5 | null; dateISO: string | null }
export interface HoursEntry { days: readonly Weekday[]; opens: string | null; closes: string | null; confirmed: boolean }  // "HH:mm"; null = closed

export interface ReservationConfig { provider: string | null; url: string | null; label: string; opensInNewTab: boolean }
export interface SiteConfig {
  name: string; tagline: string; description: string; cuisine: "Asian fusion";
  url: string | null;                                // the ONLY reader of NEXT_PUBLIC_SITE_URL is content/site.ts
  address: Confirmable<readonly string[]>; phone: Confirmable<string>; email: Confirmable<string>;
  instagram: { handle: string | null; url: string | null };
  location: { mapsUrl: string | null; embedUrl: string | null; lat: number | null; lng: number | null };
  reservation: ReservationConfig;
}
```

TypeScript rules:
- Data files use `export const dishes = [...] as const satisfies readonly Dish[]` (typo-safe, literal-preserving). Declare `StoryContent`, `GalleryItem`, `MenuSection` in this same file in the same style, reusing `ImageAsset`.
- Use `readonly` arrays, `import type`, discriminated and string-literal unions (no `enum`), `unknown` plus narrowing instead of `any`. No non-null `!`, no `as` casts other than `as const`, no `React.FC`. Make switches exhaustive (`default: { const _n: never = x; return _n; }`).
- Custom-property styles are typed once, in `Reveal.tsx`: ``export type CSSVars = CSSProperties & Record<`--${string}`, string>``, so `style={{ "--d": "180ms" }}` needs no cast.
- Branch on data with one pure resolver, not scattered `if (url)`:

```ts
// src/lib/reservation.ts
export type ReservationAction =
  | { kind: "link"; href: string; label: string; external: boolean }
  | { kind: "dialog"; label: string };
export function resolveReservation(r: ReservationConfig): ReservationAction {
  return r.url ? { kind: "link", href: r.url, label: r.label, external: r.opensInNewTab } : { kind: "dialog", label: r.label };
}
```

`src/lib/cn.ts` is the only class helper: `export function cn(...p: ReadonlyArray<string | false | null | undefined>): string { return p.filter(Boolean).join(" "); }`. Never build class names by concatenation (`aspect-${n}`): Tailwind cannot see them. Dynamic values go in `style`: ``style={{ aspectRatio: `${w} / ${h}` }}``.

## 4. Tokens and Tailwind v4

- All tokens live in one `@theme { ... }` block in `src/app/globals.css` (imported once, in `app/layout.tsx`). There is no `tailwind.config.js` and no `postcss.config.*`; Tailwind runs through `@tailwindcss/turbopack` in `next.config.ts`. Hand-written CSS in `globals.css` is limited to: tokens, base, noise texture, the `data-reveal` system, photo scrims (`rgba(32,33,30,...)`) and the global `:focus-visible` rule. No CSS Modules, styled-jsx or CSS-in-JS.
- Token names map 1:1 to utilities (use exactly these):
  - Colour: `--color-paper|stone|ink|ink-soft|muted|muted-strong|line|accent|accent-deep|bone` => `bg-paper text-ink border-line`.
  - Type: `--text-wordmark|display-xl|display-lg|display-md|display-sm|lead|body|small|label` => `text-display-lg`, each with a `--text-*--line-height` companion (display 0.95-1.05, body 1.65); `--tracking-display: -0.02em`, `--tracking-label: 0.18em`.
  - Breakpoint `--breakpoint-3xl: 120rem`; easing `--ease-out`, `--ease-in-out` (`ease-out`); durations `--dur-fast|base|slow|cine` used as `duration-(--dur-base)`.
  - Layout `--gutter`, `--content-max`, `--content-narrow`, `--section-y` used as `px-(--gutter)`, `max-w-(--content-max)`, `py-(--section-y)`.
- **Never** write a hex, `rgb()` or arbitrary colour (`bg-[#...]`, `text-[color:...]`) in a component. Need a colour that has no token? Stop and ask for a token. Dark surfaces: `bg-ink text-bone` (raised: `bg-ink-soft`). `text-muted` only for decorative or >=24px text; small secondary text is `text-muted-strong`.
- Tailwind emits only the theme variables it sees used. If raw CSS or `style={{}}` reads `var(--color-x)` and it is undefined in DevTools, move that token into `@theme static`.
- Shape: radius 0 everywhere. Allowed exceptions are `MediaImage shape="arch"` (`999px 999px 0 0`, max 2 per page) and `shape="circle"` (seal/pin). No `rounded-*` elsewhere, no `shadow-*`, no `bg-gradient-*` (photo scrims excepted), no cards-with-borders around images.
- Use native v4 utilities: `aspect-4/5` not `aspect-[4/5]`; `hover:` is already gated by `@media (hover: hover)` in v4, so do not re-wrap it (hand-written CSS must). Focus styling is global (2px `--color-accent`, 3px offset; `--color-bone` on dark surfaces): never write per-component outlines and never `outline-none`.
- Fonts (`app/layout.tsx`, `next/font/google` only, self-hosted at build, no `<link>` to Google Fonts, no third family):
  - ``Fraunces({ subsets: ["latin"], axes: ["opsz", "SOFT"], style: ["normal", "italic"], display: "swap", variable: "--font-fraunces" })`` and ``Hanken_Grotesk({ subsets: ["latin"], display: "swap", variable: "--font-hanken" })``. Omit `weight`: both are variable fonts and `axes` is only valid for variable fonts. Put both `.variable` classes on `<html>`.
  - Map them in `@theme inline { --font-display: var(--font-fraunces); --font-sans: var(--font-hanken); }` (naming the next/font variable `--font-display` itself would make the alias self-referential) and use `font-display` / `font-sans`. The display `font-variation-settings: "opsz" 144, "SOFT" 40` lives in one `@utility` in globals.css, never inline.

## 5. Responsive layout (mobile, tablet, laptop, large desktop)

- **Mobile first.** Unprefixed classes are the 375px design; add `md:` (768, tablet), `lg:`/`xl:` (1024/1280, laptop), `3xl:` (1920, large desktop). Do not write `max-*:` variants or desktop-first overrides. QA widths: 375, 430, 768, 1024, 1440, 1920.
- **Recompose, do not stack.** Below `md` each multi-column section must use at least one deliberate composition: offset (`ml-[12%]`, `mr-[8%]`), 2-up image pair (`grid-cols-2`), alternating alignment (`self-end`), or a staggered top margin. Don't: `flex-col` + same order + full-width images. Do: Story at 375 = wide image, then text, then a narrower image pushed right.
- >= `md` use `grid md:grid-cols-12 md:gap-x-[calc(var(--gutter)/1.5)]`; place children with `col-span-*`/`col-start-*`, never with margins or fixed widths.
- **Horizontal padding and max width belong to `Container`** (`width="wide"` => `--content-max`, `"narrow"` => `--content-narrow`). Sections never add their own `px-*`. Full-bleed media sits outside `Container` inside a parent with `overflow-x-clip` (not `overflow-hidden`, which breaks `position: sticky`).
- Viewport height is `svh`: `min-h-svh`, `h-svh`. Never `h-screen`, `min-h-screen`, `100vh` or `100dvh`. Section rhythm is `py-(--section-y)`.
- Type is the fluid tokens only: `text-display-lg`, `text-body`. No `text-[Npx]`, no `sm:text-xl md:text-3xl` ladders. Prose measure `max-w-[34rem]`. The wordmark tokens fill the width: test that "TINMO" is not clipped at 375 and 1920.
- Touch targets are >= 44x44px (`min-h-11 min-w-11`); the visual can be smaller than the hit area.
- **No horizontal overflow, ever.** In DevTools at each QA width: `document.documentElement.scrollWidth > document.documentElement.clientWidth` must be `false`. Fixed-pixel widths, `w-screen` and negative margins larger than the gutter are the usual culprits.
- Image `sizes` follow the real layout (section 7), not the breakpoint you happen to be on.

## 6. Semantic HTML and accessible interaction

- `<html lang="en-GB" suppressHydrationWarning>` (the motion-ok script edits `class` before hydration; see `preventing-flash-before-hydration.md`). Skip link is the first element in `<body>`: `<a href="#main" className="sr-only focus:not-sr-only ...">Skip to content</a>`. Landmarks: `<header>`, `<nav aria-label="Primary">`, `<main id="main" tabIndex={-1}>`, `<footer>`; a second `<nav>` needs a different `aria-label`.
- Headings: exactly one `<h1>` (Hero), one `<h2>` per section, `<h3>` for items; never skip a level; choose the level for structure and the size with `text-*` classes. Every section is `<section id="story" aria-labelledby="story-heading">` with `id="story-heading"` on its `<h2>` (the Hero is `id="top"` labelled by its `<h1>`). Anchors are exactly `top story menu atmosphere reviews visit reserve`.
- Use the right element: navigation is `<a>`/`next/link`; an action is `<button type="button">`. Never `<div onClick>`, never `role="button"` on a link. Hours are a `<dl>`, nav links a `<ul>`, captions `<figcaption>` inside `<figure>`.
- External links: `target="_blank" rel="noopener noreferrer"` plus `<span className="sr-only">(opens in new tab)</span>`. Link text stands alone ("View full menu", never "click here").
- Dialog: native `<dialog>` + `showModal()` (focus trap, Esc, focus restore come free). `aria-labelledby` points at its heading, backdrop click closes (`e.target === e.currentTarget`), `onClose` is the single place that syncs React state, and the page behind is locked with `body:has(dialog[open]) { overflow: hidden }`. `MobileMenu` follows the same pattern; its toggle has `aria-expanded`, `aria-controls` and a label that flips between "Open menu" and "Close menu".
- Video control is a real `<button aria-pressed>` labelled "Pause background video" / "Play background video". Decorative SVG gets `aria-hidden="true" focusable="false"`; informative SVG gets `role="img"` + `aria-label`.
- Split text (RevealText) must keep one accessible string: `<span className="sr-only">TINMO</span>` plus `aria-hidden` letter spans.
- Motion: reveals hide content only under `html.motion-ok` and without `data-in`; with JS off or reduced motion everything is visible. Contrast: text on photos sits on a scrim >= 4.5:1; never put `text-muted` under 24px.

## 7. Images and video

- Always `MediaImage` -> `next/image` with `fill` inside the aspect box (`style={{ aspectRatio }}` from the asset) and `position: relative` on that box. Never a raw `<img>` (ESLint `@next/next/no-img-element` is on), never `unoptimized`, never remote URLs: `next.config.ts` has no `remotePatterns` and must not gain one.
- `next.config.ts` sets `images.qualities: [60, 75, 85]` (required since Next 16; other values are coerced with a dev warning) and `formats: ["image/avif", "image/webp"]`. Use 75 by default, 85 for hero/full-bleed, 60 for tiny secondary crops.
- **Next 16 deprecates `priority`; use `preload`.** `MediaImage`'s `priority` prop maps to `preload` and is set on exactly one image: the hero poster. If separate portrait and landscape posters exist, use `loading="eager"` + `fetchPriority="high"` on each instead (docs: do not `preload` when the LCP candidate varies by viewport). Everything else lazy-loads (default).
- `sizes` must match the rendered width: full-bleed `100vw`; half-width `(min-width: 768px) 50vw, 100vw`; capped by the container `(min-width: 1536px) 768px, (min-width: 768px) 50vw, 100vw`. Missing `sizes` on a `fill` image makes the browser assume `100vw`.
- Alt: specific and under ~125 characters ("Hands pouring tea into a stone cup"), no "image of". Purely decorative: `alt=""` + `aria-hidden` (`asset.decorative`). `object-position` comes only from `asset.focal`.
- Masters: WebP <= 2200px wide, <= 260KB, made with `node scripts/optimize-image.mjs <in> <out-base> --width N --ratio W:H --position attention|fx,fy --quality 80` (default `--grade tinmo`); paste the printed `blurDataURL` and `color` into `content/media.ts` and add the licence to `public/media/CREDITS.md`. Raw downloads live in the scratchpad `raw-media/` directory, never in the repo, and are never executed.
- Hero video markup: `muted loop playsInline preload="metadata" poster={...}`; no `autoPlay` attribute and no `<source media>` (unreliable across browsers). `HeroVideo` picks `portrait` vs `landscape-720|1080` in an effect (`matchMedia("(orientation: portrait)")`, then viewport width).
- Hero video playback: call `play()` only when all hold: not `prefers-reduced-motion: reduce`, Save-Data off, element intersecting. Pause on leaving the viewport and on `document.hidden`. A rejected `play()` sets `blocked` and shows the Play button. Save-Data check without a cast: `const c: unknown = Reflect.get(navigator, "connection"); const save = typeof c === "object" && c !== null && "saveData" in c && c.saveData === true;`.
- Budgets: 1080p MP4 <= 3.5MB, 720p <= 1.8MB, portrait 720x1280 <= 1.6MB, H.264 `yuv420p`, `+faststart`, audio stripped, 10-14s. No GIFs, no iframe embeds in the hero, no video library.

## 8. Loading, error and fallback states

TINMO is statically rendered, so most "loading" is perceptual and must never be faked (no `setTimeout` spinners). The states that exist, and their owners:

| State | Handling |
|---|---|
| Image loading / failed | Blur placeholder while loading; `onError` swaps to a stone panel (below) |
| Video loading / blocked / reduced motion / Save-Data | Poster is always the fallback; `blocked` (rejected `play()`) shows the Play button |
| Map not configured / embed fails | `MapPlaceholder`; `<iframe loading="lazy" title="Map showing TINMO">` only when `embedUrl` is set |
| Contact value unconfirmed | Plain text placeholder, never an anchor |
| Empty list (`dishes`, `reviews`, `items`) | Section returns `null` and its link is absent from `navigation.ts`; no empty headings |
| Reservation unconfigured | Dialog with explanation; `ReservationCTA` repeats the same text inline so no-JS visitors are not stranded |
| Route error / unknown URL | `app/error.tsx` (client; props `{ error, retry }`, call `retry()`, not `reset`), `app/global-error.tsx` (own `<html>`/`<body>`), `app/not-found.tsx` linking to `/` and `/#reserve`; no `loading.tsx` (nothing async) |
| No JS / reduced motion | Content fully visible; only enhancement is lost |

```tsx
// MediaImage.tsx (client) - the image failure pattern
const [failed, setFailed] = useState(false);
if (failed) {
  return (
    <div role="img" aria-label={asset.decorative ? undefined : asset.alt} aria-hidden={asset.decorative || undefined}
         style={{ aspectRatio: `${asset.width} / ${asset.height}`, backgroundColor: asset.color }}
         className={cn("relative flex items-end", className)}>
      <span className="m-3 bg-stone px-2 py-1 text-label uppercase tracking-label text-muted-strong">Image unavailable</span>
    </div>
  );
}
return (
  <div className={cn("relative overflow-hidden", className)} style={{ aspectRatio: `${asset.width} / ${asset.height}` }}>
    <Image src={asset.src} alt={asset.decorative ? "" : asset.alt} aria-hidden={asset.decorative || undefined}
           fill sizes={sizes} quality={quality} preload={priority}
           placeholder="blur" blurDataURL={asset.blurDataURL} onError={() => setFailed(true)}
           ref={(img) => { if (img?.complete && img.naturalWidth === 0) setFailed(true); }}  // error can fire before hydration
           style={{ objectPosition: `${asset.focal.x}% ${asset.focal.y}%` }} className="object-cover" />
  </div>
);
```

Placeholder labels ("Phone number to be added", "Placeholder — illustrative dishes") are component-owned constants rendered only while `!confirmed` / `isPlaceholder`: flipping the data flag removes the label with no second edit. They are meant to vanish, so they are not owner-edited copy.

**No fake interactions.** A control either performs its real action or is visibly disabled with an adjacent explanation (native `disabled` plus a visible note linked by `aria-describedby`). Banned: `onClick` no-ops, `cursor-pointer` or hover effects on non-interactive nodes, carousel arrows/filters that do nothing, forms without a real endpoint, invented ratings or counts, timer-driven spinners, links to `#`, to pages that do not exist, or to unconfigured social URLs.

Never swallow errors with an empty `catch` and never log them (`console.*` is banned); handle the state or let the route boundary render it.

## 9. Next 16 specifics

- Metadata (Server Components only): static `export const metadata: Metadata` in `layout.tsx` with `metadataBase: site.url ? new URL(site.url) : undefined`, `title: { default: "TINMO", template: "%s — TINMO" }`, and `robots: { index: false, follow: false }` until `site.url` is set; `alternates.canonical` only when `site.url` is set. `menu/page.tsx` exports its own `metadata = { title: "Menu" }`. `robots.ts` (`MetadataRoute.Robots`) and `sitemap.ts` mirror the same rule. - `dangerouslySetInnerHTML` has exactly two legitimate uses: that JSON-LD script (`app/page.tsx`) and the motion-ok script in `<head>` (`app/layout.tsx`): `if(!matchMedia("(prefers-reduced-motion: reduce)").matches)document.documentElement.classList.add("motion-ok")`.
